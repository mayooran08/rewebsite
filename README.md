# Gevitha Kunaratnam – website

Bilingual (EN/FR) static site served by GitHub Pages at https://gevithakunaratnam.ca

## Managing testimonials (no code needed)

Testimonials are stored in `data/testimonials.json` and shown on:
- the Testimonials page (`/en/testimonials/`, `/fr/temoignages/`)
- a "What clients say" strip on the home page (entries marked **featured**, max 3)

### Edit with Pages CMS (form-based, recommended)
1. Go to https://app.pagescms.org and sign in with GitHub.
2. Open the `rewebsite` repository, then **Testimonials**.
3. Add, edit, reorder or delete entries, then save. Changes go live in a few minutes.

Fields: client name, city, testimonial (English / French), stars (1–5), date or year,
**Show on the home page**, **Published** (switch off to hide an entry without deleting it).

If a French text is missing, the English one is shown on the French page (and the other way round).

### Edit directly on GitHub
Open `data/testimonials.json` on github.com, click the pencil icon, edit, then **Commit changes**.

Only publish testimonials that the client has approved in writing.

## Rebuilding pages (developers)
Pages are generated by `tools/build.mjs`: run `node tools/build.mjs`, then commit the result.

## Managing the blog (no code needed)

Articles are Markdown files in `content/blog/en/` (English) and `content/blog/fr/` (French).
Use Pages CMS (https://app.pagescms.org) → **Blog posts (English)** or **Articles de blogue (français)** → **Add**.

- Fill in title, date, short summary, optional cover image, and write the article.
- Switch **Published** on to show it on the site. Posts with Published off stay hidden (drafts).
- To link an English and a French version of the same article, type the **same word** in the "pair" field of both.
- Images: upload about 1200 px wide, under 300 KB.
- After saving, the site rebuilds and publishes by itself (GitHub Action "Build and deploy site"), about 2–4 minutes.

Each language has its own blog page and RSS feed (`/en/blog/feed.xml`, `/fr/blogue/feed.xml`).

Preview drafts locally: `node tools/build.mjs --drafts` (do not commit that output).

## Hosting
The site is published by the GitHub Action in `.github/workflows/deploy.yml`
(Settings > Pages > Source = GitHub Actions). Every push to `main` rebuilds all pages, including blog posts, and deploys them.
